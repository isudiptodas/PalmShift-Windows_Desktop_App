# Palm Shift
![palm-shift](https://github.com/isudiptodas/PalmShift-Windows_Desktop_App/blob/main/assets/palmshift-screen.jpg)

## Control mode :
*hand tracking movememt based desktop interaction*

- Pinch to select / double click
- two finger swipe up, down / left, right
- pinch open / close to zoom in / zoom out

## Aura mode :
*Real time camera filters based on hand movement detection*

- Water distortion
- Ink drip
- Neon lines
